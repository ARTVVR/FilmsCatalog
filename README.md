# FilmsCatalog
Link: https://glittering-snickerdoodle-335cbd.netlify.app/
🎬 Films Catalog  Films Catalog is a web application for searching and exploring movies. The project allows users to browse a catalog of popular films, search by title, filter by genre and rating, and view detailed information about each movie on its individual card.
